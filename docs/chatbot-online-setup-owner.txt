--------------------------------------------------------------------------------
الجزء 1 — حفظ الأسرار في Supabase (الخطوة الأهم)
--------------------------------------------------------------------------------

  1. افتح المتصفح وادخل إلى:
     https://supabase.com/dashboard

  2. سجّل الدخول واختر مشروع تفوق
     (معرّف المشروع الحالي: vnphkmvzglbaxfbvnowp)

  3. من القائمة الجانبية:
     Project Settings  (أيقونة الترس ⚙)

  4. من القائمة الفرعية اختر أحد الخيارين (حسب واجهة Supabase):
     • Edge Functions
     • أو: Secrets / Function Secrets

  5. أضف السرّ الأول:
     ┌─────────────────────────┬──────────────────────────────────────────┐
     │ الاسم (Name)             │ DEEPSEEK_API_KEY                         │
     │ القيمة (Value)          │ [الصق مفتاح DeepSeek — يبدأ عادةً بـ sk-...] │
     └─────────────────────────┴──────────────────────────────────────────┘
     اضغط Save / Add secret

  6. أضف السرّ الثاني:
     ┌─────────────────────────┬──────────────────────────────────────────┐
     │ الاسم (Name)             │ ASSISTANT_IP_HASH_SALT                   │
     │ القيمة (Value)          │ [الصق السلسلة العشوائية من المطوّر]         │
     └─────────────────────────┴──────────────────────────────────────────┘
     اضغط Save / Add secret

  7. تأكد أن الاسمين مطابقان حرفياً (حساس لحالة الأحرف):
     DEEPSEEK_API_KEY
     ASSISTANT_IP_HASH_SALT

--------------------------------------------------------------------------------
الجزء 2 — تحديث قاعدة البيانات (جدول الحصص اليومية)
--------------------------------------------------------------------------------

  المساعد يحتاج جدولاً في قاعدة البيانات لتتبع الحد اليومي لكل مستخدم/زائر.
  إذا لم تُطبَّق هذه الخطوة، المساعد الذكي قد لا يعمل على الإنternet.

  ── (من لوحة Supabase — بدون Terminal) ──
  1. من القائمة: SQL Editor
  2. New query
  3. الصق المحتوى كاملاً في الملف chatbot-quota-setup.sql
  4. اضغط Run
  5. يجب أن تظهر رسالة نجاح (Success)

--------------------------------------------------------------------------------
الجزء 3 — نشر دالة faq-assist على السحابة
--------------------------------------------------------------------------------

  الدالة (Edge Function) هي ما يتصل بـ DeepSeek بشكل آمن من الخادم.
  ملف الدالة هو: supabase/functions/faq-assist/index.ts
  (ليس index.html)

  ── (من لوحة Supabase / المطوّر) ──
  1. من القائمة: Edge Functions
  2. ابحث عن faq-assist أو Deploy function
  3. إذا لم تكن الدالة موجودة، اطلب من المطوّر النشر عبر Terminal:
       supabase link --project-ref vnphkmvzglbaxfbvnowp
       supabase functions deploy faq-assist
  4. تأكد من: supabase/config.toml يحتوي
       [functions.faq-assist]
       verify_jwt = false

  بعد النشر، تأكد أن الدالة faq-assist تظهر بحالة Active / Deployed.

الجزء 4 — إعدادات موقع الويب (Vercel / Netlify / Lovable / استضافة أخرى)
--------------------------------------------------------------------------------

  ┌──────────────────────────────┬─────────────────────────────────────────┐
  │ VITE_SUPABASE_URL            │ https://vnphkmvzglbaxfbvnowp.supabase.co│
  │ VITE_SUPABASE_PUBLISHABLE_KEY│ [anon public key من Supabase → API]     │
  │ VITE_SUPABASE_PROJECT_ID     │ vnphkmvzglbaxfbvnowp                    │
  └──────────────────────────────┴─────────────────────────────────────────┘

  أين تجد VITE_SUPABASE_PUBLISHABLE_KEY؟
  Supabase → Project Settings → API → anon public key

  ⚠ لا تضف DEEPSEEK_API_KEY أو ASSISTANT_IP_HASH_SALT هنا
  ⚠ لا تضف VITE_SUPABASE_FUNCTIONS_URL على الإنتاج (للتجربة المحلية فقط)

  بعد أي تغيير في إعدادات الاستضافة: أعد نشر الموقع (Redeploy).
